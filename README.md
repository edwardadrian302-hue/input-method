# 潮汐拼音

一款简洁、离线的 Windows 中文拼音输入法。无需账号，没有广告、遥测、云同步或自动联网更新。

当前版本：**0.3.0 预览版**。面向 Windows 10/11 x64 的 64 位应用。

## 安装

1. 运行 `ChaoxiPinyin-0.3.0-preview-win-x64-Setup.exe`。
2. 按向导选择安装目录，默认 `D:\ChaoxiPinyin`，并允许 Windows 管理员权限请求。
3. 按 **Win + 空格**，选择 **“潮汐拼音 · 离线拼音”**。

安装不会更改默认输入法。若切换列表中没有出现潮汐拼音，保存文件后注销并重新登录，再试一次。

## 输入

| 功能 | 操作或示例 |
|---|---|
| 全拼 | `nihao` → 你好，`qishangbaxia` → 七上八下 |
| 补全与声母缩写 | `shenm` / `sm` → 什么，`zenm` → 怎么 |
| 选择候选 | 数字 **1–9**；空格选择首选 |
| 翻页 | **- / =** 或 **PageUp / PageDown** |
| 修改与取消 | **Backspace / Esc** |
| 中英文切换 | 单按 **Shift**，或点击输入法的 **中 / 英** 按钮 |
| 标点 | 中文模式默认使用中文标点；英文模式直接输入英文标点 |

输入拼音后按逗号或分号，会提交首选并追加标点。单按 Shift 切换时，也会先提交当前首选。

候选窗每页显示九个候选，宽度随内容调整，并适应屏幕缩放。内置雾凇中文词库，安装和输入均可离线使用。

## 设置

从开始菜单打开 **“潮汐拼音设置”**，或右键点击输入法的中 / 英按钮。

- **外观**：字号 10–24 磅，默认 12 磅，支持即时预览。
- **标点**：可在中文模式下使用英文标点。
- **补全**：拼音补全与声母缩写默认开启。
- **模糊音**：z/zh、c/ch、s/sh、n/l、en/eng、an/ang、in/ing 可分别开启，默认关闭。
- **学习**：开启或关闭本地短词学习，清除已学习的词条。

修改后点击 **“应用设置”**。调整拼写规则时需要准备离线索引，等待完成后即可继续输入。

## 本地数据

本地学习默认开启，仅保存已提交的 **1–4 个纯汉字词条及次数**，最多 4096 条，用于调整同页候选排序。不保存原始拼音、英语、数字、长句或按时间排列的输入历史。

关闭学习后，已有数据保留，但不参与排序、不继续更新；清除学习数据不会影响内置词库。词条中也可能包含个人信息，可随时关闭学习并清除。

数据保存在 `%LOCALAPPDATA%\ChaoxiPinyin`，包括设置、明文词频表和离线词库缓存。

## 卸载

先切换到其他输入法，再通过 Windows **“已安装的应用”** 或开始菜单 **“卸载潮汐拼音”** 卸载。卸载默认保留本地数据；如不需要，请先在设置中清除学习数据。系统提示需要重启时，请按提示操作。
