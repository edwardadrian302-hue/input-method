# 简拼 JianPin

Windows 10/11 x64 离线搜狗双拼输入法，首版优先面向 64 位浏览器。

目前为开发预览版。具备原生 TSF 接入、Rime 离线转换、9 个候选、中文标点、短词本地学习和设置窗口。浏览器实机兼容与 Windows 10/11 双系统验收仍需进行，不能视为已经完成。

## 使用

1. 编译：`powershell -ExecutionPolicy Bypass -File scripts/build.ps1`。
2. 在管理员 PowerShell 中运行编译产物 `dist/install.ps1`，默认安装到 `D:\JianPin`。安装脚本不更改默认输入法。
3. 注销并重新登录，按 `Win + 空格` 选择“简拼 · 离线双拼”。保留原有输入法作为备用。
4. 运行安装目录中的 `JianPinSettings.exe` 控制学习、清除数据和字号。

| 操作 | 按键 |
|---|---|
| 搜狗双拼 | `nihk` → 你好，`vsgo` → 中国，`bzj;` → 北京 |
| 选择候选 | `1–9`；空格选第一项 |
| 翻页 | `-` / `=` 或 PageUp / PageDown |
| 修改与取消 | Backspace / Esc |
| 中英文切换 | 单独按一下 Shift |
| 系统输入法切换 | Win + 空格 |

候选采用竖排，减少 9 个长词挤出屏幕的情况；预编辑区域显示原始双拼码。

## 隐私行为

- 程序没有网络客户端、遥测、更新器、同步服务、剪贴板读取或键盘全局钩子。
- 独立的本地引擎进程通过仅允许当前用户访问、拒绝远程连接的命名管道接收输入法请求。
- Rime 自带用户词库始终关闭，避免默认的长句学习。自有学习只保存 **1–4 个汉字的短词及次数**，最多 4096 条；短语也可能包含个人信息，超过 4 字的内容不学习；不保存拼音、上下文、按时间排列的输入历史或英语/数字。
- 学习默认开启；关闭后保留数据，但不参与排序、不继续更新。清除后词频表为空，内置词库保留。
- 首版学习只调整当前候选页内排序，不跨页提升词条，也不支持自定义造长词。
- 数据位于 `%LOCALAPPDATA%\JianPin`，其中 `words.tsv` 是明文词频表，`settings.ini` 是设置，`engine` / `cache` 是离线词库缓存。操作系统备份或用户主动同步这些文件不受本程序控制。
- 引擎禁止文件日志，编译测试只输出检查结果，不输出实际用户输入。

“不保存输入历史”不代表词频表没有个人信息；常用词本身可能包含个人信息。可关闭学习并清除。

## 当前边界

- 目标系统为 Windows 10/11 x64，当前只构建 64 位接入 DLL。32 位应用、ARM64、游戏、远程桌面暂不作为支持范围。
- 需要人工验证浏览器中的 input、textarea、contenteditable、地址栏、密码框和焦点切换；见 `docs/ACCEPTANCE.md`。
- 程序与安装包尚未进行代码签名。首次构建含官方预编译 librime DLL，来源及哈希见依赖锁文件，不声称全部依赖都已从源码重建。
- 使用搜狗双拼键位，不包含搜狗程序、云服务或其词库。
- 编译工具放在 D 盘项目 `.tools` 中，运行输入法不需要编译器。

## 卸载

先切换到其他输入法，按需要在设置中清除学习数据。管理员 PowerShell 执行安装目录的 `uninstall.ps1`。注销并重新登录后删除安装目录；脚本不会强制关闭浏览器或删除其他输入法。
