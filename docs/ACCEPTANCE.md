# 浏览器验收清单

状态：待安装后的人工实测。目标 Windows 10 x64 / Windows 11 x64，64 位 Edge / Chrome；其他浏览器单独记录。

- 普通 input：输入 `nihao`，空格得到“你好”；`beijing` 得到“北京”。
- 第三个字母：`x` → `xu` → `xue`，每步预编辑更新，“学”可选；`daxuefengshan` 可连续输入。
- textarea：连续输入、回车换行、退格修改、Esc 取消。
- contenteditable：候选跟随光标；选择词不多插入、不丢字。
- 每页显示最多 9 个候选，数字 9 确实选第 9 项；`-` / `=` 翻页。
- 输入中点击另一输入框或切换标签页：旧拼音不进入新输入框。
- Ctrl+C/V/A、Alt+Tab、Win+空格不被输入法抢占；Shift 单按切换中英文，组合按键不误切换。
- 密码框直接输入，不出现候选、不更新词频。
- 学习开启：选后面的短词，下次同页提升；关闭后恢复基础排序且词频文件不更新。
- 清除：词频表为空，基本输入仍可用。
- 连续句子不作为长词保存，英语和数字不写词频。
- 100%、150%、200% 缩放；屏幕边缘候选不越界。
- 断网后首次启动、词库部署和所有输入功能正常。
- 任务管理器/网络监视确认本程序没有网络连接；检查用户目录无输入日志。
- 卸载、注销后原有输入法正常，潮汐拼音已从输入法列表移除。

每次实测记录系统版本、浏览器版本、缩放比例、通过/失败和复现步骤。

EXE 安装验收（尚待实测）：中文向导、自定义目录、拒绝覆盖无关非空目录、注册失败回滚、旧脚本版原目录升级、文件占用提示、开始菜单设置入口、Windows 卸载入口、卸载后其他输入法正常、用户学习数据保留。更换安装目录前先卸载旧版。程序安装后的缓存必须从双拼重建为全拼。

- 任务栏或语言栏中/英按钮图标、提示、点击切换、右键设置；Shift 切换与 Shift 组合键不冲突。
- 空闲时逗号/分号；nihao 后直接逗号/分号；中文模式英文标点开关；英文模式标点直通。

- 可视化设置的应用与重启持久化；补全关闭与模糊音七组独立开关；更改后索引准备状态与界面不冻结。
- 从早期版本卸载再安装、更名注册、原有输入法保持可用。未执行这些实机项目之前不能称为正式成品。
