# 实现说明

浏览器通过 TSF 调用 `ChaoxiPinyin.dll`；DLL 在编辑会话中更新 Windows composition 和候选窗口。通过当前用户专属的本地命名管道，将全拼按键交给 `ChaoxiPinyinBroker.exe`；所有窗口的 Rime 会话由单个进程管理，避免多进程共享用户数据库。

进程间消息固定大小，并限制响应时间。管道 ACL 限于当前用户 SID，拒绝远程客户端；会话 ID 使用服务器读取到的实际客户端 PID 作为命名空间。转换失败不把键盘永久锁住。引擎启动、词库编译都不在浏览器线程执行。

Rime 自带用户学习完全关闭。潮汐拼音维护有界词频表，默认保存已提交的 1–4 字纯中文词条和次数，可选 8/16 字，最多 8192 条；采用临时文件替换写入，清除仅影响此表。关闭学习时保留表但不读取它进行排序、不更新它。核心不会读取前后文或剪贴板。

核心源文件：`src/tsf.cpp` 系统接入，`src/engine.cpp` 引擎与短词学习，`src/broker.cpp` IPC 服务，`src/settings.cpp` 设置界面。

待实机验证的高风险边界：TSF 编辑锁与焦点切换、浏览器自定义编辑器、密码作用域、高分屏、多显示器、注销/卸载后 DLL 生命周期。不能用引擎测试替代这些验收。

0.5.0 IPC（v5） 使用新的管道名称和协议魔数，避免连接仍在运行的旧版引擎。产品 UI、二进制文件名和用户目录更名为潮汐拼音 / ChaoxiPinyin；原 TSF CLSID、语言配置 GUID、安装器 AppId 保持不变，支持旧安装身份升级。

`CandidatePanel` 为 TSF 和可视化预览共用绘制代码，默认 12 磅、内容自适应宽度。`ModeButton` 实现标准 TSF 语言栏按钮。0.5.1 起单按 Shift 通过 Rime Return 原样提交未转换的字母后切换模式，不提交中文首选或带自动分节空格的预编辑文本；点击按钮仍先提交首选。单独标点上屏返回插入范围并明确设置光标，避免无 composition 的插入失败。

配置窗口通过后台线程提交单次 Configure 请求。引擎线程写入本地 Rime custom 配置，重建拼写索引，再创建新会话；已部署的中文词表复用。重建前清理的只有明确的派生 schema/prism 文件，解决 Rime 秒级时间戳导致连续设置不刷新的问题。所有候选转换和设置写入仍由单个本地 broker 串行执行。

## 0.4.0 本地辅助功能

`Profile` 统一保存设置、词频与 4096 条以内的手填词条。使用带结束标记和条数的 UTF-8 TSV，以同目录临时文件、FlushFileBuffers 和原子替换写入 `profile.tsv`；设置、恢复与手填修改先验证，保存失败回退内存状态。自动学习保存失败只报告状态，不影响上屏。仅在不存在新档案时读取 0.3 旧文件，旧文件保留；明确清除学习时同时删除旧词频文件。

导出备份复用完整档案格式；导入限制 4 MiB、8192 条学习记录、4096 条手填记录，拒绝非法 UTF-8、未知版本、重复记录、越界参数和不完整文件。它是完整替换，不是合并。

`Lexicon` 只读取打包的固定版雾凇中文词表，生成按全拼与汉字排序的只读内存索引。纠错查询编辑距离为一（插入/删除/替换/相邻交换）的全拼词条，查询长度 4–48 字母，最多补入三个纠错候选；保留原引擎首选，仅手填词条可优先。覆盖的是完整词拼音，不是任意句子的智能纠错。增加的候选使用额外页，原本 Rime 首页面内候选不丢失，后续继续原引擎翻页。

上屏联想从刚提交词条查找词库中以它开头的较长词，仅展示剩余后缀，最多九项。它不读取应用上下文，不保存上下文关系，不引入预测插件或新依赖。候选响应带独立 prediction 标志，TSF 只画窗口，不创建拼音 composition；数字/空格插入后缀，Esc/失焦/中英文切换关闭，字母开始下一次拼音。

个人词条 1–32 个 BMP 汉字，拼音 1–96 个拉丁字母（空格/撇号可输入但会归一化）。手填词条与自动学习分开；不自动推断拼音或支持跨词拼接。词条修改通过旧键与新键在同一次持久化操作完成。

新版互斥量与管道均使用 v5 命名，Rime 数据和缓存位于 `engine-v5` / `cache-v5`，避免仍在运行的 0.3 引擎阻止新版启动或共享部署目录。产品身份与用户数据根目录保持不变。

## 0.5.0 词库导入与下载

`DictionaryImport` 只读 UTF-8 文本，单文件上限 16 MiB；支持默认 Rime text/code/weight 列及 TSV，不解析 YAML 引用或执行代码。ImportPreview 过滤内置和个人重复条目，保存内存快照；ImportCommit 绑定实际管道客户端进程与令牌，五分钟内确认，只合并预览快照。超过个人词库 4096 条上限整批失败；保存复用 Profile 原子替换及回退。ImportCancel 丢弃快照。导入词条属于个人词库，包含于现有备份。

仅设置程序显式下载时使用 Windows WinHTTP，固定 HTTPS GitHub raw 主机和雾凇 ext 路径；系统证书校验，禁止重定向，自动解压，解压后大小上限 16 MiB、单次网络等待 10 秒、下载总时长约 180 秒。网络在设置工作线程运行，不在输入进程或 broker 执行。临时下载文件读取预览后删除；无输入数据上传。不是自动定时更新，也不是云候选或实时热搜服务。

学习排序改为在 Rime 已有的同长度候选位置中重排，保留不同长度候选的原始位置；避免高频“人”挤到完整“人生长恨”之前。
