# 实现说明

浏览器通过 TSF 调用 `ChaoxiPinyin.dll`；DLL 在编辑会话中更新 Windows composition 和候选窗口。通过当前用户专属的本地命名管道，将全拼按键交给 `ChaoxiPinyinBroker.exe`；所有窗口的 Rime 会话由单个进程管理，避免多进程共享用户数据库。

进程间消息固定大小，并限制响应时间。管道 ACL 限于当前用户 SID，拒绝远程客户端；会话 ID 使用服务器读取到的实际客户端 PID 作为命名空间。转换失败不把键盘永久锁住。引擎启动、词库编译都不在浏览器线程执行。

Rime 自带用户学习完全关闭。潮汐拼音维护有界词频表，只保存已提交的 1–4 字纯中文短词和次数；采用临时文件替换写入，清除仅影响此表。关闭学习时保留表但不读取它进行排序、不更新它。核心不会读取前后文或剪贴板。

核心源文件：`src/tsf.cpp` 系统接入，`src/engine.cpp` 引擎与短词学习，`src/broker.cpp` IPC 服务，`src/settings.cpp` 设置界面。

待实机验证的高风险边界：TSF 编辑锁与焦点切换、浏览器自定义编辑器、密码作用域、高分屏、多显示器、注销/卸载后 DLL 生命周期。不能用引擎测试替代这些验收。

0.3.0 IPC 使用新的管道名称和协议魔数，避免连接仍在运行的旧版引擎。产品 UI、二进制文件名和用户目录更名为潮汐拼音 / ChaoxiPinyin；原 TSF CLSID、语言配置 GUID、安装器 AppId 保持不变，支持旧安装身份升级。

`CandidatePanel` 为 TSF 和可视化预览共用绘制代码，默认 12 磅、内容自适应宽度。`ModeButton` 实现标准 TSF 语言栏按钮，按 Shift 与点击调用相同的切换流程；未提交拼音先提交首选。单独标点上屏返回插入范围并明确设置光标，避免无 composition 的插入失败。

配置窗口通过后台线程提交单次 Configure 请求。引擎线程写入本地 Rime custom 配置，重建拼写索引，再创建新会话；已部署的中文词表复用。重建前清理的只有明确的派生 schema/prism 文件，解决 Rime 秒级时间戳导致连续设置不刷新的问题。所有候选转换和设置写入仍由单个本地 broker 串行执行。
