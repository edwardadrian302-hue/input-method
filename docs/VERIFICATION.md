开发日期：2026-11-04。当前构建为 0.2.0 开发预览版，已从搜狗双拼改为全拼。本轮没有执行新版系统安装/卸载。只读检查发现已有 `D:\JianPin\JianPinBroker.exe` 正在运行，因此测试使用独立命名空间，保留用户正在使用的旧版进程。

最终结果：**32 项真实引擎检查通过；100 次 IPC 请求通过；TSF 文本编辑会话测试通过。** 测试主机 Windows build 26300.9711；没有 Windows 10 独立测试环境。

## 已验证

- 使用 D 盘便携 LLVM-MinGW 工具链编译 x64 DLL、引擎进程、设置程序和测试程序。
- LLVM-MinGW 与 librime 发布包的 SHA-256 与 GitHub 官方资产摘要一致，记录于 `downloads.lock.json`。
- 真实 librime 集成测试：全拼 `nihao` / `zhongguo` / `beijing`、9 个候选、数字 9 选词、空格选词、翻页、退格、取消、中文标点、独立会话、本地学习开关和清除；确认无 Rime 用户数据库。
- 全拼回归：`xu` 加 `e` 后预编辑更新为 `xue`，可找到“学”；`daxuefengshan` 连续输入有候选；TSF 文本存储也确认第三个字母更新预编辑。
- 词频与开关跨进程重启持久化；超过 4 字的长句不学习；模拟词频文件被锁定，确认保存失败不影响汉字上屏。
- 本地进程通信：独立测试引擎连续 100 次命名管道请求/响应。
- Windows TSF 集成测试：真实 Windows 文本存储、编辑会话、composition 和 range；验证上屏不重复、取消只删除预编辑、焦点丢失回调、禁用输入上下文和 Shift 英文直通，最后检查 COM 对象释放。
- 候选窗与独立预览共用 `CandidatePanel` 绘制代码，生成 96/144/192 DPI 位图；已目视检查白底、浅绿高亮、序号、候选和页脚无重叠。位图不包含真实窗口圆角裁剪及桌面阴影，高分屏桌面和多屏仍待实测。
- Inno Setup 6.7.4 官方下载已核对 GitHub SHA-256 和有效的 Pyrsys B.V. Authenticode 签名，便携工具位于 D 盘项目 `.tools`。中文安装向导与文件清单已编译生成 EXE；未运行安装器完成系统安装，不能把编译成功等同于注册/卸载验收通过。

## 测试边界

TSF 测试为了不安装系统输入法，只替代了未注册 TIP 无法使用的键盘订阅；按键和焦点回调由测试程序调用。因此不证明系统注册、实际浏览器键盘路由或密码框输入作用域已经通过。禁用输入上下文测试不等于所有网页密码框实测。

命名管道/TSF 测试需要普通 Windows 用户会话。本轮受限会话测试出现等待引擎超时，最终在普通 Windows 用户环境使用独立测试管道重跑通过。在受限 AppContainer 沙箱中，命名对象访问受限，不能用该沙箱结果判断正常用户环境下的行为。
