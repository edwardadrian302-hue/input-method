# 验证记录

日期：2026-11-04。当前为 **潮汐拼音 0.3.0 开发预览版**，名称为潮汐拼音。当前代码已经构建，本轮不安装或卸载用户的系统输入法。测试使用工程独立数据目录与管道，不读取真实用户学习数据。

## 已通过

- 使用 D 盘便携 LLVM-MinGW 构建 x64 输入法 DLL、本地引擎、原生设置窗口、资源图标与测试程序。未安装 C 盘 C++ 工具链，未修改系统 PATH。
- **54 项真实 Rime 引擎检查**：全拼、第三个字母更新、九候选、数字选词、翻页、退格、Esc、中文标点、会话隔离、学习开关/清除/重启持久化、长句不学习、词频写入失败不丢字。
- 新增词库检查：`qishangbaxia` 首选“七上八下”；`shenm`、`sm` 找到“什么”，`zenm` 找到“怎么”。
- 空闲逗号/分号、拼音后逗号/分号、中文模式英文标点均通过。七组模糊音、补全开关关闭及恢复、字号和模糊音重启持久化通过。
- **100 次命名管道请求**与 Windows TSF 文本编辑会话测试通过：composition、commit、cancel、焦点、禁用上下文、物理逗号/分号键上屏、拼音后标点、英文标点直通、Shift 完整按下/抬起流程和切换时提交未选词、中英文按钮点击回调/状态/图标，以及 COM 对象释放。
- 原生设置窗口已经实际打开、截图检查，字号预览、七组模糊音、标点、补全、学习开关和按钮文字均可见，没有重叠；可视化设置通过单次后台请求提交，重建索引期间显示等待状态。
- 候选布局共用 CandidatePanel 绘制代码，默认 12 磅，最小宽度 150 DIP、最大 440 DIP；按本页文字和工作区限制调整。独立预览检查 96/144/192 DPI、长候选扩宽与边界限制。预览位图不含桌面阴影与窗口外部圆角裁剪。
- 雾凇词库固定 commit 与每份源文件 SHA-256 存于 `dictionary.lock.json`，导入生成时逐项校验；保留词表来源头部及 GPL-3.0 许可。Rime 与编译器发布包的官方 SHA-256 核验记录仍在 `downloads.lock.json`。

## 本轮修复的具体问题

1. 默认候选字体和最小宽度过大：默认改为 12 磅、缩小留白并按内容测量。
2. 中英文切换：Shift 按下明确交由输入法处理；切换前提交首选；新增标准 TSF 中/英状态按钮。
3. 空闲标点插入：旧的无预编辑插入路径在真实 TSF 会话返回 E_INVALIDARG；改为返回插入范围并明确设置光标后通过。逗号/分号的引擎提交流程也覆盖了拼音尚未选词的情况。
4. 词库与不完整拼音：新增雾凇中文基础/扩展词库及可配置补全。
5. 设置连续切换：Rime 修改检测使用秒级时间戳，同秒更改可能复用旧规则；现在更改拼写时只失效派生的 schema/prism，再重建索引，测试覆盖快速关闭、启用与恢复。

## 必须保留的测试边界

TSF 测试使用真实 Windows 文本存储、编辑会话、composition 和 range；为了不注册系统输入法并避免干扰当前语言栏，**替代了键盘订阅和语言栏订阅**，按键、焦点及按钮点击由测试程序调用。按钮状态/图标检查不等同于 Windows 任务栏实际显示通过。因此这些测试不证明新版系统注册、真实浏览器路由、任务栏图标展示、网页密码框或双系统兼容已经通过。

命名管道和 TSF 测试在普通 Windows 用户环境运行；受限沙箱可能限制命名对象，不能用沙箱失败判定普通用户环境行为。已知测试主机 Windows build 为先前记录的 26300.9711；本轮没有独立 Windows 10 环境，也未将该旧记录当作新系统版本核验。
