- 补上九键拼音筛选：有输入时，左侧标点栏临时显示当前候选对应的音节，点击 song / rong 等选音；选音后仅保留对应读音的字词。可逐音节筛选，点“撤销”逐步取消；清空或选词后释放相应状态。无输入时恢复标点栏，符号页始终可用。

## 0.3.2-preview 比例调整

根据手机反馈微调九键比例：竖屏主按键高度从 55dp 降至 49dp，左侧标点栏从 38dp 加宽至 48dp，标点文字单独放大；保留四个标点入口和原底部功能行高度。九键主体（不含工具栏、候选和系统导航）从 238dp 降至 220dp。26 键与横屏行高保持既有值，数字页沿用加宽的标点栏。九键拼音字母显示继续保留。

安装包 build/ChaoxiPinyin-0.3.2-preview-android-arm64.apk，versionCode=5。布局检查覆盖 60 种配置，包含实际使用的紧凑行高；新版模型示意图已目视检查，非手机截图。真机触摸手感与显示效果仍待用户覆盖安装后验收。

## 0.3.1-preview 九键拼音显示

九键输入的预编辑现在显示当前 Rime 候选对应的拼音字母，取代按键数字。例如 5664 → long、64426 → ni hao、64426744543 → ni hao shi jie；键盘顶部与输入框共用该显示。未能解码的尾部显示 ABC / DEF 等字母组，保留已选中文片段，不把内部编码作为拼音。九键本身有歧义，拼音会随当前候选解析变化。原样提交仍保留原按键数字，选中文词不受影响。

安装包 build/ChaoxiPinyin-0.3.1-preview-android-arm64.apk，versionCode=4，与 0.3.0 同签名，支持覆盖升级。184 项真实 Rime 共用核心回归及 Android 构建、Lint、签名与 16 KB ZIP 对齐检查通过；手机显示与触摸仍待用户实测。本轮没有安装、启用、提交源码或发布。

## 0.3.0-preview 样式与设置

## 0.2.0-preview 功能基础

- 键盘顶部常驻“设置”与“切换九键 / 切换26键”按钮，布局选择保存在手机本地，下次输入继续使用。英文与密码输入仍显示 26 键。
- 九键按 ABC / DEF / GHI / JKL / MNO / PQRS / TUV / WXYZ 分组，一次按键表示一组字母，由 Rime 解码；64426 → 你好，64426744543 → 你好世界。支持空格、触屏选词、退格和翻页。1 为分词键，不在空输入时输出标点。切换布局时将未选择的预编辑原样提交，避免丢字。
- 九键方案使用独立 schema/prism，与全拼共用中文词库；内部映射字母不作为英文候选展示。九键输入不提供英文前缀补全，切回 26 键可继续使用英文候选。
- 0.2.0 引入候选间隔；当前 0.3.0 已改为横向留白与分隔线样式。
- 主应用现在是可滚动的真实设置页：中文布局、学习开关、补全、4/8/16 字学习长度、自动学习与个人词条容量、已用条数、清除自动学习，以及系统键盘管理入口。
- 容量每类 1–100000 条，低于已用数量拒绝保存；设置与容量一次原子保存。档案格式升级到 v2，新版仍可读 v1，旧版不能读 v2。手机备份界面仍未实现，请使用相同签名覆盖升级，勿先卸载。

## 范围

同一个仓库维护 Windows 与 Android。Android 主应用和 InputMethodService 在一个 APK 中，Java 触屏界面经 JNI 直接调用现有 C++ Engine；Windows TSF、命名管道、WinHTTP 和桌面设置不在 Android 中编译。现有英文、候选排序、个人档案格式与 Rime 方案共用，不另造一套词库引擎。

早期 0.1.0-preview：26 键全拼、触屏候选和翻页、英文原文和补全、中文标点、中英文切换、符号页、长按退格、英文大写、本地学习。密码框直接输入，不将字符送入拼音引擎；应用要求不进行个性化学习时，仅在本轮禁止学习，不改持久设置。

个人词库管理、备份恢复、模糊音等设置、联网新词下载尚无手机界面，不宣称桌面功能已全部移植。首版清单不声明 INTERNET 权限，不上传输入数据。

## 系统与数据

ARM64，最低 Android 11 / API 30。构建使用已实际获取的 Google 稳定包 android-36_r02（compile/target API 36），不是仅凭网页文案设置一个下载清单中不存在的 SDK。更高系统兼容性需要真机验证，不能把成功编译当作最新系统已验收。

手机数据保存在应用私有 files/UserData，词库资源复制到 files/runtime-0.2.0；不使用 Windows 的安装目录，也不读电脑个人数据。卸载 Android 应用会删除其数据；首版尚无备份界面，升级请使用相同签名覆盖安装，不要卸载后再装。关闭系统备份，避免默认将个人档案上传到设备云备份。

初始化与按键使用单线程队列，JNI 再加互斥。输入框更换时使用代次号丢弃过期响应，清除旧会话；有未完成按键时暂时隐藏候选，避免选择旧列表索引。资源准备完成之前不接受拼音按键，避免把首批按键静默提交为其他内容。初始化失败可点击提示重试。

## 工具与构建

工具和缓存都在 D 盘工程 .tools，系统 PATH 不变：NDK 28.2.13676358、CMake 3.22.1、Gradle 8.13、AGP 8.13.2，JDK 使用 D:/Environment/jdk-21.0.11。Google 工具源与摘要记录在 android-tools.lock.json。原生依赖固定到 librime 锁定提交所引用的依赖提交，另使用 Boost 1.89.0，见 android-dependencies.lock.json。

1. `python scripts/prepare-android-tools.py` 获取并校验官方工具；使用项目 sdkmanager 检查 SDK 许可。
2. `python scripts/prepare-android-sources.py` 获取固定依赖和 Boost 1.89.0 的头部与许可证（跳过超过 Windows 路径限制的文档），并获取 RapidJSON 固定版本许可。
3. `powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1` 编译 ARM64 Rime、共用核心、JNI 和 APK，并运行 Android Lint。

脚本只构建，不执行 adb install，不替用户启用键盘。APK 使用项目私有签名，密钥和密码文件保存在 `.tools/android-signing`，不提交仓库。请将该目录私下备份；后续升级需要相同密钥。
